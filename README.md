# PR Images

Github does not offer an official way to upload images to PR from the API or MCP.
This repository is a temporary workaround to allow coding agents to add images to PRs in my other repositories.

Each target repository will get a folder here.
The folder will contain subfolders using the id of the PR.

```
README.md
lkr-planner/
lkr-planner/133/
lkr-planner/133/example.png
```
